# Homework 4

This folder contains the Homework 4 submission for the stock visualization application.

The project is split into two main parts:

- `client/`: React frontend for visualizing stock prices, t-SNE data, and news.
- `server/`: FastAPI backend that serves stock data, news, and t-SNE data from MongoDB.

The frontend loads data from the backend API instead of reading local data files directly. The backend uses the MongoDB database `stock_agothankar`.
