# ECS 273 HW3 — Stock Explorer (D3 Visualizations)

Interactive dashboard that visualizes stock data from HW1 (price time-series and
news articles) and HW2 (t-SNE projection of LSTM autoencoder latent
representations) using D3 inside React + TypeScript.

## What's inside

```
src/
├── App.tsx                       # 3-panel layout, dropdown, view linking
├── data/stocks.ts                # 20 tickers + sector mapping
└── component/
    ├── option.tsx                # Dropdown menu (grouped by sector)
    ├── LineChart.tsx             # View 1 — Open/High/Low/Close lines, sticky Y-axis,
    │                             #          horizontal zoom slider, horizontal scroll,
    │                             #          hover crosshair + tooltip
    ├── TSNEScatter.tsx           # View 2 — t-SNE scatter, sector colors, selection
    │                             #          highlight (larger circle + bold label),
    │                             #          d3.zoom (wheel-zoom + drag-pan + dbl-click reset)
    └── NewsList.tsx              # View 3 — title + date list; click to expand body

public/data/
├── demo.json                     # Placeholder (not used by app)
├── stockdata/<TICKER>.csv        # 20 files, 2 years of OHLCV from HW1 Task 1
├── stocknews/<TICKER>/*.txt      # Original per-article files from HW1 Task 2
├── stocknews/<TICKER>.json       # Same news parsed into a single JSON per ticker
│                                 # (loaded by the browser since it cannot list dirs)
└── tsne.csv                      # ticker, x, y, sector — generated by training the
                                  # HW2 LSTM autoencoder and projecting the 16-dim
                                  # latent space to 2D with sklearn TSNE
```

## How `tsne.csv` was generated

`generate_tsne.py` (kept at the repo root for reference) loads the 20 CSVs from
`public/data/stockdata`, builds a `StockDataset`, trains the HW2
`LSTMAutoencoder` for 50 epochs, extracts the 16-dim latent vectors with
`get_latent`, then runs `sklearn.manifold.TSNE(n_components=2, perplexity=4,
random_state=42, init='pca')` and writes `ticker, x, y, sector` rows.
