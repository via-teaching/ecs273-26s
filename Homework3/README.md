# Homework 3: Stock Data Visualization

## Introduction

This project is a React-based web application that provides interactive visualizations for stock market data. It allows users to explore stock performance through multiple visualization techniques, including line charts for historical price trends, T-SNE scatter plots for stock relationship analysis, and a news feed showing relevant articles for each stock. The application supports visualizations for 20 major stocks.

## Features

- **Stock Selection**: Dropdown menu to select from 20 major stocks
- **Stock Overview Line Chart**: Interactive line chart showing historical stock prices
- **T-SNE Scatter Plot**: Dimensionality reduction visualization showing relationships between stocks
- **News Feed**: News articles related to the selected stock

## Setup Instructions

### Prerequisites

- Node.js (v14 or higher)
- npm (Node Package Manager)

### 1. Navigate to the project folder

```
cd Homework3/priramachandran
```

### 2. Install required Node.js packages

```
npm install
```

### 3. Start the development server

```
npm run dev
```

### 4. Visit the application in your browser

The application will typically run at: http://localhost:5173
