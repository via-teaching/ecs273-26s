# ECS 273 - Homework 3

This project is a dashboard for viewing stock prices, stock news, and t-SNE stock data using React and D3.

- stock_overview_line_chart.jsx shows the Open, High, Low, and Close stock prices as line charts for the selected stock.
- t-sne_scatter_plot.jsx shows a t-SNE scatter plot where stocks are grouped by sector and the selected stock is bigger.
- news_list.jsx shows news articles for the selected stock and lets the user click to expand the article content.

Tools Used
- JavaScript
- React + Vite
- D3.js
- Tailwind CSS

## Run the code
```bash
cd Homework3/nbetoshana
npm install
npm run dev
```

In the terminal, hold down Ctrl and click on http://localhost:5173/ to open the link in your browser.
